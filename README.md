Pour ce projet, j'ai développé un site e-commerce appelé GearShop.

Qu’est-ce que GearShop ?
GearShop est une boutique en ligne spécialisée dans la vente d’équipements et d’accessoires pour le sport.
Le nom vient de l’anglais :
Gear : qui signifie équipement, matériel
Shop : qui signifie magasin

* Objectif du projet
L’objectif était de concevoir un site fonctionnel et responsive permettant :

-De présenter différents produits (équipements & accessoires)
-D’ajouter des articles à un panier
-D’accéder à un formulaire de contact
-D’intégrer un système de connexion simple

 *Les fonctionnalités développées
1-Page d’accueil (index.html)
.Présentation de la boutique
.Mise en avant de différentes catégories de produits : Équipements & Accessoires
.Design responsive 

2-Affichage des produits
.Chaque produit a une image, un nom et un bouton “Acheter”
.Lorsque l’utilisateur clique sur "Acheter", l’article est ajouté au panier

3-Panier interactif
.Un compteur affiche le nombre d’articles ajoutés
.Système simple de suivi des achats via JavaScript

4-Menu de navigation
.Liens vers différentes pages : Accueil, Produits, Contact, Connexion
.Un bouton “menu” est prévu pour les écrans mobiles

5-Page de contact (contact.html)
.Formulaire avec champs : nom, e-mail, message
.Prévu pour que les utilisateurs puissent poser des questions ou faire des demandes

6-Connexion utilisateur 
.Interface de base pour se connecter
.Champs de nom d’utilisateur et mot de passe (pas encore connecté à une base de données)
